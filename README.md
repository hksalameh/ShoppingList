# مشترياتي — ShoppingList

تطبيق أندرويد عربي بسيط لإدارة قائمة مشتريات المنزل.

## النسخة الأولى
- قائمة ثابتة قابلة للتعديل للمواد المعتادة.
- اختيار المواد المطلوبة وإضافتها إلى سلة التسوق.
- تعليم كل مادة بأنها تم شراؤها أثناء التسوق.
- عرض المتبقي من المشتريات بسهولة.
- إضافة مواد جديدة وتعديل أو حذف المواد الحالية.
- حفظ كل البيانات محليًا على الهاتف والعمل بدون إنترنت.
- زر إنهاء التسوق لمسح حالة الجولة الحالية مع إبقاء القائمة الأساسية.

## استيراد قائمة من صورة
- افتح تبويب «صورة» للتصوير أو الاختيار من المعرض، أو شارك صورة من واتساب إلى «مشترياتي».
- يقرأ التطبيق النص العربي على الجهاز باستخدام [PaddleOCR PP-OCRv5 Mobile](https://huggingface.co/PaddlePaddle/arabic_PP-OCRv5_mobile_rec) و[ONNX Runtime](https://onnxruntime.ai/). تعتمد نتائج الخط اليدوي على وضوح الكتابة والصورة.
- راجع الأسماء والكميات وعدّلها أو احذفها، ثم اعتمد المطلوب للسلة. يعاد استخدام المادة الموجودة عند تطابق الاسم بعد توحيد التشكيل والمسافات وبعض أشكال الحروف.
- عند أول بناء، ينزّل Gradle نماذج القراءة المضمّنة ويتحقق من بصماتها SHA-256. القراءة بعد التثبيت تعمل دون اتصال.

## التقنية
- Kotlin
- Jetpack Compose
- Material 3
- تخزين محلي على الجهاز

يبني GitHub Actions ملف APK ويشغّل اختبارات الوحدة. يتطلب تحديث تطبيق مثبت إصدارًا أعلى وتوقيعه بنفس مفتاح النسخة المثبتة. تستخدم مخرجات `assembleDebug` مفتاح التصحيح في بيئة البناء.

يبني الأمر `gradle :app:assemblePreview` تطبيقًا تجريبيًا مستقلاً باسم «مشترياتي (نسخة الصور)» يمكن تثبيته بجانب النسخة الحالية. يحتفظ كل تطبيق بقوائمه الخاصة. هذه النسخة التجريبية مخصصة لأجهزة ARM64.

تبدأ التثبيتات الجديدة بقائمة فارغة. استخدم زر الحذف بجانب البحث لمسح القائمة والسلة بعد التأكيد، أو أزل المشتريات المنجزة من السلة مع إبقاء مواد القائمة.
