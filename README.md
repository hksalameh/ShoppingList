# مشترياتي — ShoppingList

تطبيق أندرويد عربي بسيط لإدارة قائمة مشتريات المنزل.

## النسخة الأولى
- قائمة ثابتة قابلة للتعديل للمواد المعتادة.
- اختيار المواد المطلوبة وإضافتها إلى سلة التسوق.
- تعليم كل مادة بأنها تم شراؤها أثناء التسوق.
- عرض المتبقي من المشتريات بسهولة.
- إضافة مواد جديدة وتعديل أو حذف المواد الحالية.
- حفظ كل البيانات محليًا على الهاتف والعمل بدون إنترنت.
- زر إنهاء التسوق لمسح حالة الجولة الحالية مع إبقاء القائمة الأساسية.

## المرحلة التالية
- التقاط صورة لقائمة مكتوبة بخط اليد أو اختيار صورة من المعرض.
- تحويل الصورة إلى قائمة قابلة للمراجعة والتعديل قبل اعتمادها.

## التقنية
- Kotlin
- Jetpack Compose
- Material 3
- تخزين محلي على الجهاز

سيتم إنشاء APK تلقائيًا بواسطة GitHub Actions بعد كل تحديث ناجح على الفرع `main`.
